# Лабораторна робота № 10
## Файлове введення-виведення та збереження стану за допомогою менеджерів контексту

### Індивідуальний варіант: № 1
- **Предметна область:** Телеметрія сонячної електростанції
- **Вхідний CSV-файл:** `solar.csv`
- **Критерій фільтрації та розрахунку:** напруга $> 220\text{ В}$; розрахунок потужності $P = U \cdot I$
- **Вихідний CSV-файл:** `cleaned_solar.csv`
- **Магічна сигнатура BIN-файлу:** `0x534F4C52` (ASCII: `'SOLR'`)
- **Вихідний JSON-файл стану:** `solar_snapshot.json`

### Структура проєкту
- `.vscode/launch.json` — конфігурація запуску та налагодження у VS Code
- `.gitignore` — правила виключення службових і тимчасових файлів
- `telemetry_pipeline.py` — основний модуль конвеєра обробки CSV, бінарного аудиту та експорту стану в JSON
- `solar.csv` — вхідні дані телеметрії
- `cleaned_solar.csv` — відфільтровані валідні записи з розрахованою потужністю
- `firmware_sample.bin` — тестовий бінарний файл прошивки із заголовком `'SOLR'`
- `solar_snapshot.json` — серіалізований підсумковий знімок стану системи
- `README.md` — опис виконання лабораторної роботи

### Результати перевірки конвеєра
- Оброблено рядків у `solar.csv`: `6`, валідних (напруга $> 220\text{ В}$): `4`, відсіяно: `2`.
- Сумарна потужність валідних записів: `12646.84 Вт`, середня потужність: `3161.71 Вт`.
- Бінарний файл `firmware_sample.bin` пройшов перевірку сигнатури `0x534F4C52`, визначено версію прошивки `v2.5`, загальний розмір `12` байтів та розмір корисних даних `6` байтів (`seek()` / `tell()`).
- Підсумковий стан збережено у `solar_snapshot.json`.
